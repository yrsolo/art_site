# ART_SITE

Монорепозиторий для сайта-портфолио художницы с публичной витриной, галереей работ и закрытой админкой. Проект готовится под быстрый MVP на `Next.js + TypeScript + Tailwind CSS` с деплоем в контейнере в Яндекс Облако.

## Что Это

Сайт должен объединять:
- публичные страницы портфолио;
- детальные страницы работ;
- контакты и информацию об авторе;
- простую защищённую админку для управления картинами и изображениями.

## Зачем Это Нужно

Нужна рабочая база, из которой можно быстро собрать первую версию сайта, не теряя контроль над архитектурой, документацией и будущим деплоем. На старте важно сохранить простоту: один репозиторий, один контейнер, минимально разумная безопасность и понятная структура для роста.

## Основные Возможности MVP

- Публичные страницы: `home`, `gallery`, `artwork/[slug]`, `about`, `contacts`
- Админка с логином по паролю и `httpOnly` cookie-сессией
- CRUD для картин
- Загрузка изображений в Yandex Object Storage
- Хранение метаданных в JSON с заделом под последующую БД
- Поддержка нескольких дизайн-направлений до выбора финального визуального стиля
