# Deploy

## Целевой Контур

Планируемый деплой:
- один Docker-образ;
- запуск в Яндекс Облаке;
- домен `art.solofarm.ru`.

## Почему Так

- проще сопровождать MVP;
- нет необходимости делить приложение на функции;
- удобно держать публичный сайт, админку и API в одном runtime.

## Что Нужно Подготовить Позже

- `Dockerfile`
- инструкция локальной сборки
- перечень обязательных env для прода
- шаги публикации образа
- шаги привязки домена и TLS
