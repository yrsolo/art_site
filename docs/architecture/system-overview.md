# System Overview

## Цель Системы

Дать художнице простой управляемый сайт, который:
- красиво показывает работы;
- позволяет редактировать контент без разработчика;
- быстро деплоится в Яндекс Облако;
- не усложняет MVP лишними технологиями.

## Планируемый Контур MVP

Один `Next.js`-проект в `apps/web`, который содержит:
- публичные страницы;
- закрытые admin routes;
- server actions и route handlers для операций с данными;
- интеграцию с Object Storage;
- слой доступа к метаданным работ.

## Основные Подсистемы

### Public UI

Показывает страницы сайта и читает только опубликованные или видимые работы.

### Admin UI

Позволяет логиниться, редактировать список картин, менять порядок, загружать изображения и скрывать работы.

### Content Storage

На старте:
- метаданные — JSON-файл или совместимый storage adapter;
- изображения — Yandex Object Storage.

### Auth

Простая серверная проверка логина/пароля с сессией в `httpOnly cookie`.

## Архитектурный Вектор На Потом

Следующее расширение должно быть дешёвым:
- заменить JSON на PostgreSQL или YDB;
- оставить внешний контракт данных стабильным;
- не переписывать публичный UI из-за смены хранилища.
