# Frontend

## Стек

- `Next.js`
- `TypeScript`
- `Tailwind CSS`

## Роль Frontend-слоя

Frontend должен покрывать два режима:
- публичный портфолио-сайт;
- интерфейс администратора.

## Требования К UI-архитектуре

- не смешивать админские компоненты с публичными;
- держать общий дизайн-слой заменяемым;
- не привязывать layout жёстко к одному эскизу, пока финальный стиль не выбран;
- переносить HTML-референсы в нормальные React-компоненты, а не вставлять их как сырой финальный код.

## Работа С Дизайн-Эскизами

Источники лежат в `ref/template/`.

Пока дизайн не выбран окончательно, нужно предусмотреть:
- общую модель контента;
- единый backend-контур;
- возможность быстро переключать или сравнивать визуальные варианты.

Практический вывод:
- данные и маршруты должны быть общими;
- тема и компоненты представления должны быть изолированы настолько, насколько это разумно для MVP.
