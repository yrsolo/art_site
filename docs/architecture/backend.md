# Backend

## Общий Подход

Backend не выделяется в отдельный сервис. Его роль выполняет серверная часть `Next.js`.

## Что Нужно Реализовать В MVP

- `login`
- `logout`
- `get artworks`
- `create artwork`
- `update artwork`
- `hide/delete artwork`
- `upload image`

## Требования

- проверка пароля только на сервере;
- сессия через `httpOnly cookie`;
- отдельный слой доступа к данным, чтобы потом можно было заменить JSON-хранилище;
- отдельный слой интеграции с Object Storage.

## Что Не Нужен Делать Сразу

- полноценную RBAC-систему;
- регистрацию пользователей;
- сложный audit log;
- отдельный API gateway;
- очереди и фоновые пайплайны без прямой необходимости.
