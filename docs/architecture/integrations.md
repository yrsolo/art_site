# Integrations

## Основные Интеграции MVP

### Yandex Object Storage

Используется для хранения изображений работ.

Нужно предусмотреть:
- загрузку оригинала;
- генерацию или хранение preview-версии;
- безопасную работу через env-переменные;
- явный слой клиента, чтобы не размазывать SDK по приложению.

### Yandex Cloud Deploy

Текущий целевой вариант деплоя:
- один Docker-контейнер;
- запуск в Serverless Container или Cloud Container;
- домен `art.solofarm.ru`.

## Нефункциональные Требования

- не хранить секреты в репозитории;
- не завязывать код на локальные абсолютные пути;
- не предполагать, что файловая система контейнера подходит для постоянного хранения данных.
