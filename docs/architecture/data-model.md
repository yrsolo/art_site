# Data Model

## Сущность Artwork

На старте система опирается на сущность `artwork`.

Поля MVP:
- `id`
- `slug`
- `title`
- `description`
- `year`
- `size`
- `medium`
- `status`
- `imageOriginal`
- `imagePreview`
- `order`

## Статусы

Базовые статусы:
- `available`
- `sold`
- `hidden`

## Принцип Хранения

- метаданные работ отделены от файлов изображений;
- UI работает с доменной моделью, а не с форматом конкретного хранилища;
- адаптер данных должен позволить позже заменить JSON на БД.

## Что Стоит Предусмотреть Сразу

- валидацию `slug`;
- стабильную сортировку по `order`;
- возможность не показывать `hidden` работы на публичном сайте.
