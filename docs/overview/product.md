# Product Overview

## Продукт

`ART_SITE` — сайт-портфолио художницы с фокусом на визуальную подачу работ, простую навигацию и удобное управление контентом без тяжёлой CMS.

## Пользовательские Контуры

Есть два основных контура:
- публичный сайт для посетителей;
- закрытая админка для владельца сайта.

## Публичная Часть

MVP публичной части включает:
- главную страницу;
- галерею работ;
- страницу отдельной картины;
- страницу об авторе;
- страницу контактов.

## Админка

Админка нужна для:
- входа по паролю;
- добавления и редактирования картин;
- управления порядком показа;
- скрытия и удаления работ;
- загрузки изображений в объектное хранилище.

## Ограничения MVP

- один репозиторий;
- один Next.js app;
- один Docker-контейнер;
- без сложной БД на старте;
- без лишних подсистем, не влияющих на запуск MVP.
