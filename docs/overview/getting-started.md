# Getting Started

## Текущий Статус

Репозиторий уже содержит локальный MVP в `apps/web`.

Сейчас доступны:
- публичные страницы сайта;
- переключение визуальных тем;
- локальная админка с логином;
- CRUD для картин через JSON-хранилище;
- локальная загрузка изображений в `public/uploads`.

## Где Лежит Исходный Контекст

- исходное описание задачи: `brif/brif.md`
- вводный контекст по репозиторию: `brif/info.md`
- правила онбординга для шаблона: `agent/start.md`
- дизайн-референсы: `ref/template/`

## Как Заходить В Проект

1. Прочитать корневой `README.md`
2. Прочитать [docs/README.md](../README.md)
3. Посмотреть [System Overview](../architecture/system-overview.md)
4. Проверить [work/now/current-task.md](../../work/now/current-task.md)
5. Запустить локально `npm install` и `npm run dev`
6. После этого переходить к доработкам внутри `apps/web`

## Ближайший Практический Следующий Шаг

1. Заполнить реальными данными страницу об авторе и контакты
2. Подвязать настоящие изображения вместо placeholder-файлов
3. Улучшить UX админки и добавить явный reorder-интерфейс
4. Вынести storage adapter с локального диска на Yandex Object Storage
5. После стабилизации локального сценария заняться Docker и deploy
