# Agent Workflow

## Обычный Цикл Работы

1. Прочитать обзорные документы
2. Проверить текущий tracking
3. Выполнить задачу
4. Обновить затронутые docs
5. Прогнать релевантные проверки
6. Обновить evidence

## Когда Обновлять Tracking

Обновлять `work/now/*`, если:
- задача не микроскопическая;
- есть важные промежуточные решения;
- нужно передать контекст следующему заходу.

## Что Считать Завершением Этапа

Этап считается завершённым, когда:
- изменения отражены в коде или в agreed docs;
- нет скрытых договорённостей «только в голове»;
- ясно, что делать дальше.
