# Release Flow

## Для MVP

Перед первым реальным деплоем нужно проверить:
- что `apps/web` собирается;
- что env-переменные описаны;
- что контейнер собирается локально;
- что логин в админку работает;
- что загрузка изображения работает;
- что публичный сайт отображает актуальные данные.

## Минимальный Порядок

1. Обновить docs по факту реализации
2. Прогнать релевантные проверки
3. Сверить env и deploy
4. Подготовить короткий handoff summary
